- `pastilles-avant-apres.png` : six pastilles du kit, de jour, avant et après (agrandies deux fois).
- `contrastes.json` : par page, thème et version, nombre de pastilles, contraste minimum du mot, pastilles sous 4,5:1.
- `qa.cjs` : captures avant/après (démo sans framework, plateforme, landing, kit ; 1440 et 390 px ; jour et nuit), contraste de chaque pastille contre son fond réel (couches composées).

Résultat : nuit identique au pixel sur toutes les pages ; de jour, les pixels différents sont tous à l'intérieur des pastilles ; aucune erreur de console.
